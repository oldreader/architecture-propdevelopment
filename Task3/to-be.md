# To-be
## Требования к безопасности:
1. Биометрические данные - чувствительная персоаньная инфрмация. Её необходимо передавать в обезличеном виде.
2. Необходимо осуществлять передачу по зашифрованному каналу. 
3. В идеальном варинте хотелось бы, чтобы вся биометрии происходила через сервис Интеллектуального домофона. Тогда нам не придётся  прередавть данные верез наш сервис Smart-environment.  
## Аутентификация и авторизация:
1. Аутентификация по биометрии происходит только в домофоне через передачу вектора авторизации на сторону Интеллектуального домофона. Нам здесь ничего не нужно разрабатывать.
2. Аутентификация Smart-environment => Интеллектуальный домофон происходит по идентификатору пользователя, например UUID
3. Авторизация происходит на нашей стороне - собственник определяет что клиент может делать(входить по биометрии или нет) и когда его права прекращают действия.
